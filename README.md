#  Real-Time Chat Application - ChatNova

A full-stack real-time chat application built using the MERN stack that delivers seamless one-to-one messaging with instant updates, secure authentication, and a responsive user experience. The application leverages WebSockets through Socket.io for real-time communication and follows modern development practices to ensure scalability, performance, and maintainability.
Live Demo

🔗 Application: [ChatNova](https://realtimechat-d5wt.onrender.com/)

Note: Since both the frontend and backend are deployed on Render's free tier, the server may take a few seconds to wake up if it has been inactive.
---

##  Features

-  User Authentication (JWT)
-  User Registration & Login
-  Real-Time One-to-One Chat
-  Online/Offline User Status
-  Profile Picture Support

## 🔄 Workflow

1. User registers.
2. User logs in.
3. JWT token is generated.
4. User can search other users.
5. Open a conversation.
6. Send and receive messages instantly using Socket.IO.
7. Online users are displayed in real time.

##  Project Overview

This project demonstrates the implementation of a modern real-time messaging platform using the MERN stack. It combines secure authentication, WebSocket-based communication, cloud image storage, and responsive frontend development to provide a smooth and engaging chat experience. The application is designed with scalability, performance, and clean architecture in mind, making it a strong example of a production-ready full-stack web application.
